# 设计配方多样性扩展

日期：2026-09-11。所有修改留在当前工作区，未提交、推送或部署。

## 当前范围

工作台扩展为 6 个场景、12 种布局、24 份配方起点；每类场景有 2 种结构和 4 份配方。

| 场景 | 两种结构 | 代表用途与本地交互 |
| --- | --- | --- |
| 产品展示页 | 左右分栏、主视觉居中 | 阅读产品、音频产品、创意工作室、开发工具；页内导航与体验表单 |
| 工具后台 | 侧栏导航、顶部导航 | 任务与指标工作区；搜索、筛选、新建、完成状态与异常状态 |
| 作品集 | 非对称画廊、瀑布流作品墙 | 设计档案、几何作品、影像作品、字体实验；分类与项目详情 |
| 博客杂志 | 杂志封面、长文阅读 | 主报道、栏目索引、长文与旁注；文章详情、目录跳转和订阅示例 |
| 电商精选 | 商品目录、商品详情 | 商品浏览、规格和选择；分类、数量、示例购物袋与移除 |
| 聊天应用 | 专注对话、收件箱与详情 | 消息流、会话列表和共享参考；搜索、消息输入、上下文切换和手机返回 |

主视觉提供产品界面、摄影与影像、几何构成、线条插画、纯字体、纹理与材质、数据图表七种选择。场景决定结构，配色、字体、间距、表面、动效和主视觉作为可覆盖的设计要素。

## 图片与离线

- 在“摄影与影像”中选取本地 JPG、PNG 或 WebP，原文件最大 8 MB。
- 浏览器本机解码、缩小至最长边 1600px 并重新编码为 JPEG，不上传文件；重新编码去除原图元数据，透明背景合成白色。
- 可编辑图片说明，选择填满/完整显示、靠上/居中/靠下。移除后恢复内置示例，支持撤销。
- 用户图片替换主要影像位置；次要作品保留示例内容。切换视觉类别时图片仍保留，切回摄影模式可继续使用。
- 图片随配方 JSON、参考 HTML 和 ZIP 保存。由于浏览器存储配额有限，大图片较多时会提示下载 JSON 备份。
- 内置影像复用项目已有的原创 AI 插图，明确标注为 AI 创作；线条插画与图形由确定性 SVG/CSS 绘制。
- 离线文件仍由同一套模块生成，约 832 KiB，包含全部内置配方、字体、图形和示例影像；用户图片仅进入其自己的配方与导出包。

## 兼容与约束

新版导出使用 schemaVersion 2、catalogVersion 2026.09.2。已知 v1 文件在校验原参数快照后迁移，保留原先的布局、配色、字体、密度、表面、动效以及自定义内容。起点示例内容可能随版本更新；旧参考 HTML 仍是旧视觉版本的独立依据。

不猜测迁移未知版本，不接受远程图片 URL 或 SVG 上传。非法 JSON、损坏快照和不支持的图片不会替换当前配方。图片异步处理完成时合并到最新草稿，避免覆盖期间完成的其他调整。

所有场景均为设计与本地交互参考。购物袋不创建订单、不支付；消息流返回固定的本地演示回复，不联系他人；订阅示例不提交邮箱。

## 验收范围

- 参数解析、覆盖、JSON 往返、旧文件迁移、非法导入、图片导出和 ZIP 解码由 `pnpm test` 验证。
- 24 配方 × 中英文 × 4 尺寸，合计 192 次浏览器渲染检查。
- 12 布局 × 7 主视觉，额外 84 次手机尺寸渲染检查；同时检查图片解码、横向溢出和运行异常。
- 独立验证四个新场景的筛选、详情、表单、购物袋、消息与手机导航。
- 浏览器验证图片本地转换、显示方式、刷新恢复、无效图片拒绝、JSON/ZIP 导出、旧收藏恢复以及断网图片使用。
- Safari 本地文件手工检查通过：旧配方恢复、作品集与摄影模式、本地 WebP 转换为图片预览、完整显示设置及刷新后保留。
- 截图与最终报告保存在 `output/recipes/`，不进入版本控制。自动参数校验不等于对全部组合的美学保证；视觉审阅覆盖精选配方及边界样例。

维护入口为 `src/recipes/model.ts`、`visuals.ts`、`scenes.ts`、`sceneStyles.ts` 和 `image.ts`。新增视觉类别必须同步覆盖解析、预览、说明、文件导出和离线构建。
