# 设计配方首版交付记录

日期：2026-09-11。此文记录最初的 2 场景版本。当前已扩展为 6 场景、12 布局和 24 配方，见 [扩展交付记录](design-recipe-expansion.md)。实现保留在当前工作区，未提交、推送或部署。

## 可用入口

- 在线工作台：`/compose`，首页导航、Hero 和已适配的风格详情提供入口。
- 离线工作台：构建生成 `dist/vibe-design-offline.html`，约 409 KiB，下载后可双击打开。
- 本地预览：`pnpm preview --host 127.0.0.1 --port 4178`，访问 `http://127.0.0.1:4178/compose`。

## 交付范围

| 方案要求 | 当前实现 |
| --- | --- |
| 2 个场景、4 个布局、8 个配方起点 | 产品展示页左右分栏/居中；后台侧栏/顶部导航，各 4 份精选起点 |
| 组合调整 | 6 套配色、3 套字体、3 档密度、3 套表面、2 档动效；预览、说明和 HTML 使用同一解析结果 |
| 选择与恢复 | 撤销、重做、恢复起点参数、保留兼容修改的场景切换、标题/说明/按钮文字编辑 |
| 保存与导入 | 自动保存当前配方、命名副本、本地收藏、JSON 导入导出；格式、目录版本和参数快照严格校验 |
| 交付资料 | 支持新建/修改模式；复制 Markdown，下载 JSON、独立 HTML，或包含六份文件的 ZIP |
| 参考交互 | 展示页锚点与本地表单；后台导航、搜索、筛选、新建任务、完成切换，以及正常/空/加载/错误状态 |
| 浏览体验 | 双语、亮暗工作台主题、固定设备视口、自适应预览、全屏与 Escape、移动端预览/调整切换 |
| 离线与降级 | 独立构建入口生成单文件，内嵌字体；本地存储不可用时提示备份，复制不可用时选中文本并提供下载 |
| 分发与资源 | 配方路由静态壳和 sitemap；MIT 与字体许可随包提供；不增加运行依赖或模型调用 |

## 验收证据

- `pnpm build`：通过。现有 30 种风格数据、Demo 与缩略图指纹检查通过，生成完整站点与离线工作台。
- `pnpm lint`：通过。
- `pnpm test`：10 个测试通过。其中新增检查覆盖 1,296 种参数组合的解析、语义文字配色对比、44px 操作目标参数、JSON 往返、版本拒绝、用户文字转义、最终参数一致性及独立 ZIP 解码。
- `pnpm validate:recipes`：64 次真实渲染检查，即 8 配方 × 中英文 × 390/768/1280/1440 宽度；额外检查 320px 长文本压力、减弱动态效果、实际本地交互、工作台历史与保存恢复、有效/无效导入、浏览器 ZIP/JSON 下载、全屏退出、主题、入口与断网模式。
- 无效导入保持当前配方不变；从风格详情带入起点后，刷新继续恢复用户修改。
- Chrome 强制断网后，通过 `file://` 打开生产离线文件，完成配色切换与 ZIP 下载；该阶段记录到的 HTTP(S) 请求为零。
- 强制禁用剪贴板和本地存储，验证了备份提示、文本选择与导出降级。
- Safari 手工验证本地 HTML 打开、配色切换、复制成功反馈、实际 ZIP 下载；独立解包确认六个文件完整且保存的是选中的 forest 配色。
- `pnpm validate:studio`：原有风格详情、预览面板、全屏、手机、嵌入表单及对比滚动同步回归通过。
- 人工查看了 8 份配方的桌面/手机截图，以及工作台手机调整、手机预览、英文暗色和导出弹窗。

自动验收报告位于 `output/recipes/report.json`；渲染截图与 HTML 位于同目录，原站回归报告位于 `output/studio/report.json`。这些文件为本地测试产物，不进入版本控制。

## 实现边界

- 配方在本地通过确定性规则解析，不识别截图、不调用 AI，也不提供真实后端。
- 1,296 个组合通过的是参数与导出检查；视觉审阅覆盖精选配方与边界样例，不表示对每种组合的美学作出保证。
- 内嵌拉丁字体子集；中文与技术感等宽标题使用本机回退字体，跨系统字形可能不同。
- 用户清除浏览器数据会删除本地收藏，请用 JSON 备份；跨版本文件目前严格拒绝，不进行猜测迁移。
- 5 位目标用户的产品试用、外部 AI 还原效果比较、海报/PPT/原生 App、云同步和分享链接未纳入本轮实现。

## 维护方式

`src/recipes/model.ts` 定义选项、起点、覆盖与导入校验；`render.ts` 生成参考和设计说明；`export.ts` 打包；`Workbench.tsx` 与 `workbench.css` 提供界面；`offline.tsx` 是离线入口。

修改配方或工作台后运行 `pnpm build` 更新离线文件。开发服务器启动前也会生成离线文件；开发过程中更新离线下载需执行 `pnpm recipe:offline`。新增选项需同步检查模板支持、参数归属、导出语义和跨尺寸效果。
